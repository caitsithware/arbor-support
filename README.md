# Arbor Support

**English** | [日本語](README.ja.md)

Official support channel for the Unity asset **Arbor 3**.  
For more information about **Arbor 3**, please visit <https://arbor.caitsithware.com/en/>.  
This repository does not contain any source code. Questions and bug reports are handled in **Discussions**.

## Ask a question or share feedback

👉 [Open Discussions](https://github.com/caitsithware/arbor-support/discussions)

| Category | Purpose |
|---|---|
| Q&A | How-to questions and troubleshooting |
| Bug Reports | Something isn't working as expected |
| Announcements | Updates and maintenance notices (posted by the team only) |

Please search existing Discussions before posting. Your question may already be answered.

## When posting

- Include your **version** and **OS / environment**
- For bugs, describe the **steps to reproduce**, the **expected behavior**, and the **actual behavior**
- Screenshots are welcome

### ⚠️ Do not post confidential information

Discussions are **publicly visible**. Please do not post:

- License keys, passwords, API keys, or tokens
- Personal information or customer data
- Screenshots containing any of the above (please redact them first)

## For private inquiries

For licensing, contracts, billing, or anything confidential, please contact us directly instead of using Discussions.

[Contact Us](https://caitsithware.com/en/contact-us/)

## Response policy

- Response times may vary.
- We can't promise to implement every request, but all feedback helps shape future development
- Abusive or promotional posts may be removed
